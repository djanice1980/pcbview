The DualSense controller artwork in this directory (dualsense.svg, and the
artwork embedded in controller-map.svg) is taken from the Gamepad Asset Pack:

    https://github.com/AL2009man/Gamepad-Asset-Pack
    Controller Asset Pack / DualSense Controller Image / Default /
        Theme SVG / DualSense VSCView SVG Midnight Black.svg

It is used unmodified as artwork; controller-map.svg adds pcbview's own
callout layer around it. The artwork originates with VSCView
(https://github.com/Nielk1/VSCView).

requirement that the copyright and permission notice travel with the work.
